# Landing Page Milad Ke-36 RSU 'Aisyiyah Siti Fatimah Tulangan

Landing page resmi peringatan **Milad Ke-36 RSU 'Aisyiyah Siti Fatimah (RSASF) Tulangan, Sidoarjo**, dirancang mengacu pada:
1. **Notulen Rapat Persiapan Milad ke-36** (Rabu, 4 November 2026 di Aula Nyai Siti Walidah).
2. **Logo Resmi Milad Ke-36**:
   - `logo 36.jpeg` (Versi horizontal pada header dan footer).
   - `logo 36 sqare.jpeg` (Versi square/persegi pada showcase hero section).
3. **Identitas & Warna Resmi Web**: [rsasitifatimah.com](https://rsasitifatimah.com) (Royal Blue `#0b4fa8`, Medical Teal `#08786f`, dan Metallic Gold `#ffd66b`).

## 🚀 Cara Menjalankan
Halaman ini adalah *single-page static site* murni (**HTML5 + Tailwind CSS + Vanilla JS**).
Cukup **klik ganda file `index.html`** untuk membukanya langsung di peramban apa pun (Chrome, Edge, Firefox, Safari) tanpa perlu install server backend atau database.
Tautan pendaftaran pada kartu Donor Darah dan Khitan Massal langsung mengarah ke Google Form resmi masing-masing kegiatan.
